# Online Retail Sales Analysis

## 📌 Project Overview

This project focuses on analyzing online retail sales data using Python.
The objective was to perform data cleaning, exploratory data analysis (EDA), and generate business insights from transactional retail data.

The analysis was performed using Jupyter Notebook with Python libraries such as Pandas and Matplotlib.

---

## 🛠 Tools & Technologies Used

* Python
* Jupyter Notebook
* Pandas
* Matplotlib

---

## 📂 Dataset

Dataset used:
`OnlineRetail.csv`

The dataset contains:

* Customer transactions
* Product details
* Quantity purchased
* Invoice dates
* Unit prices
* Country information

---

## 🔍 Data Analysis Performed

### ✅ Data Cleaning

* Removed missing values
* Removed duplicate records
* Converted date columns into datetime format

### ✅ Exploratory Data Analysis (EDA)

* Top-selling products analysis
* Revenue analysis
* Customer purchase behavior
* Monthly sales trend analysis

### ✅ Data Visualization

Created charts using Matplotlib:

* Top products by revenue
* Monthly sales trends

---

## 📈 Key Insights

* Identified top revenue-generating products
* Found high-value customers
* Analyzed monthly sales patterns
* Generated business insights from retail transaction data
